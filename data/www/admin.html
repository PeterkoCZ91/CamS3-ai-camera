Systemove akce

Tovarni reset smaze veskerou konfiguraci a restartuje zarizeni do AP rezimu.

API endpointy
GET /api/status - Stav systemu (JSON)
GET /api/snapshot - Snapshot (JPEG)
GET :81/stream - MJPEG stream
POST /api/settings - Zmena nastaveni
GET /api/wifi/scan - Scan siti
POST /api/wifi - Pripojeni k siti
POST /api/reboot - Restart
POST /api/reset - Factory reset
POST /api/camera/reinit - Reinit kamery
GET /api/sd/list?path=/ - SD karta
GET /api/sd/download?file= - Stahnout
DELETE /api/sd/delete?file= - Smazat
WS /ws - WebSocket (real-time status)
