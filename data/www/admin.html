System actions

Factory reset erases all configuration and reboots into AP mode.

API endpoints
GET /api/status - System status (JSON)
GET /api/snapshot - Snapshot (JPEG)
GET :81/stream - MJPEG stream
POST /api/settings - Change settings
GET /api/wifi/scan - Scan networks
POST /api/wifi - Join network
POST /api/reboot - Reboot
POST /api/reset - Factory reset
POST /api/camera/reinit - Camera reinit
GET /api/sd/list?path=/ - SD listing
GET /api/sd/download?file= - Download
DELETE /api/sd/delete?file= - Delete
GET /api/zones - Detection zones (JSON)
POST /api/zones - Add / update a zone
DELETE /api/zones?name= - Delete a zone
GET /api/roi - ROI mask + grid size
POST /api/roi - Set ROI mask
GET /api/csrf - CSRF token (auth required)
WS /ws - WebSocket (real-time status)
